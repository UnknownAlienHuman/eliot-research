# Eliot Research

A private research workspace for one owner and explicitly connected agents: shared Library, immutable captures,
deterministic canonical text, exact passages, bounded source understanding, cited answers, strict project comparisons,
bounded deep research and MCP — on Cloudflare.

**Status (2026-10-25):** the replacement architecture and implementation contracts are specified. The root Worker/Vite
shell exists, but product contours K0+ are not implemented. No D1 migration or new Cloudflare product binding described
here has been remotely applied. Legacy `apps/`, `packages/`, `crates/` and `infra/` remain donor/import evidence until
K10; they are not implementation instructions.
