# Worker composition

This is the single deployable Worker. Authenticate/validate ingress, compose the existing bindings and
cohesive application modules, and return honest results. A local helper does not require another package,
service, generic repository or forwarding port. Keep one execution owner for each real operation.
Remove unselected routes with their exclusive code instead of retaining permanent 501/503 scaffolds.
Selected unfinished behavior must remain explicitly unavailable, never simulated success.
Preserve actual source/result data, atomic updates, original paid-attempt identity and cancellation.
[Root rules](../../AGENTS.md) and [the plan](../../docs/implementation/backend-entrypoints.md) govern
scope, source retirement and checks. No deployment or live data mutation follows from local refactoring alone.
