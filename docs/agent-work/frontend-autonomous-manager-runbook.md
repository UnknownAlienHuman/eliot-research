Use root [working rules](../../AGENTS.md), the [implementation plan](../implementation/backend-entrypoints.md),

This file defines the UI-specific management boundary. It does not create checkpoint codes, claim files, approval
receipts, branches or another scheduler.

## Delivery

Choose one complete user outcome and trace its real client/server contract. Assign disjoint leaf files when parallel
work helps; the manager serializes routes, barrels, manifests, shared tokens and integration. Leaves do not create
worktrees, branches, frameworks or private task registries.

Continue through implementation, rendered inspection, integration and repair without asking the owner to choose
reversible internal details. Reuse accepted tokens/components and remove rejected variants. An unavailable optional
MCP/browser helper or independent reviewer is a stated limitation, not a reason to stop unrelated work.

Prepare the real Vite/Worker asset path and a known-good rollback artifact as part of cutover. Production deployment,
account/provider mutation, data conversion, destructive retirement and final cutover require the applicable explicit
authorization; documentation or a green build does not grant it.

## Review

Review the integrated Sources, Research, Report/Evidence, Studio/Wiki/Inbox and Connections journeys, not isolated
components. Cover representative desktop/compact/phone, light/dark, long RU/EN, useful/loading/empty/stale/denied/
offline/degraded/error states and applicable keyboard, touch, focus, scroll, accessibility, CSP, lifecycle, network and
performance behavior.

Use a fresh-context no-hint usability pass when available. Repair actual wrong turns and contract failures. Record
unavailable native/staging/live checks honestly; do not publish private source text, prompts, credentials, cookies or
provider payloads as evidence.

## Stop conditions

Stop only the affected action when:

- a missing/contradictory contract changes product truth;
- the proposed change weakens identity, authorization, privacy, citation or effect ownership;
- required access to the actual selected environment remains unavailable after a different recovery approach;
- an external/irreversible action lacks authorization.

Continue independent implementation while a narrow handoff is pending. The owner reviews the finished integrated
result, not a sequence of internal token/component/checkpoint approvals.
