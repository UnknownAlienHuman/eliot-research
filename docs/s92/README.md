# S92 setup artifacts

This directory is the in-repo home of the S92 setup track (S92 passport: PR #292, EXECUTION-STEPS-03). `s92-INPUT.draft.json` is the D1(a) local-disabled research-runtime INPUT template — owner replaces every `local-draft-*` placeholder with installed identities before real S92, and `semantic.roles` is intentionally absent because the compiler's exact-key validation (`apps/eliotr-core/src/research-owner-semantic-config.ts`) rejects unknown keys. `S92-LOCAL-RUNBOOK.md` is the setup runbook: INPUT decisions, the compile command, the exact local acceptance command sequence, and the not-applied D1(b) real-gateway variant. Validate the draft any time with `node scripts/configure-research-runtime.mjs docs/s92/s92-INPUT.draft.json --output /tmp/s92-check.json` (exit 0, zero `__DECISION_REQUIRED`).
