# Retrieval and evidence

Search returns candidate locators, not evidence. Citations resolve against exact admitted revision/bytes, current project membership and purge state. Unknown observations never imply absence or success. EXHAUSTIVE does not infer completeness from top-k or reranking. Reuse the existing native search and evidence owners; do not add a generation registry or citation database. See [ADR-0019](../../docs/adr/0019-compact-refactoring.md) and the [implementation router](../../docs/implementation/backend-entrypoints.md).
