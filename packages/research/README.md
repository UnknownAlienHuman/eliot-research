# research

Controlled research: the investigation as the durable unit, research protocols, source portfolios,
hypothesis cards, branches, counter-search, coverage receipts and artifact compilation.

Chat is an interface to an investigation, not the investigation itself. An investigation survives a
model change, a compaction, a restarted client and a handover to another agent.

Every run returns a typed disposition and a coverage receipt. Only a supported result or a properly
scoped complete-scope absence may close an inquiry; every other outcome preserves a next probe, a
narrower claim or an explicit unknown.
